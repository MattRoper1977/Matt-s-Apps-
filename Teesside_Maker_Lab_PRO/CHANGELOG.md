# Changelog

## 2.0.0 — 15 August 2026

### Platform

- Rebuilt the suite as a coordinated offline professional studio platform.
- Added the learner-facing Studio Shell and travelling Maker Passport.
- Added common shell messaging and live project-state synchronisation across all eight apps.
- Added three explicit representation relays: token → economy, hydro-board → navigation and relief → collagraph.
- Added `.makerstudio`, `.makerclass` and `.makerhub` workflow formats alongside `.makerlab`.

### Professional evidence

- Added prediction-locked Audited Trials and calibration records.
- Added baseline and Design A checkpoints with A/B replay.
- Added common decision timelines, undo/redo and visual evidence capture.
- Added source-status discipline to distinguish evidence, inference, synthetic model and creative interpretation.
- Added printable dossiers and portable project import/export.

### Teacher and moderation systems

- Added the Studio Shell and travelling Maker Passport for shared commissions, pupil journeys and representation relays.
- Added a Teacher Studio Director with resource-collision forecasting, route profiles, station cards and live workshop pulse.
- Added a Portfolio Moderation Hub with authorship audit, blind aliases, conflict ledger, balanced sampling and dossier export.

### Specialist studios

- Added physical-photo analysis and sensitivity ranking to Shadow Rig.
- Added topology, registration and safe abstract fabrication diagnostics to Token Foundry.
- Added limited reconnaissance, changing tides and route autopsy to Smuggling Rig.
- Added raking-light, distance, inverse-mould and virtual-patina diagnostics to Relief Lab.
- Added constraint solving, punch routing, repeated tolerance trials and tiled 1:1 output to Steelplate CAM.
- Added active sounding design, hidden-truth error analysis, contour nesting and conceptual cam synthesis to Hydro-Board.
- Added edition-wear memory, physical proof comparison and sensory station planning to Collagraph Engine.
- Added 12-week counterfactuals, concealed shocks, reforms, source board and perspective tribunal to Economy Lab.

### Safety and truth

- Removed operational hot-metal and reactive-patina recipes from pupil-facing workflows.
- Made classroom geometry, synthetic charts, counterfactual economies and fictional tokens explicitly non-authoritative.
- Added deployment, privacy, interoperability and safety documentation.
